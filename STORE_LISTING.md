## Detailed Description

**Meet the goblin. It lives in your browser and it has opinions about your landing page.**

PageGoblin is the website roast tool for founders, marketers, designers, and anyone who wants a brutally honest (but genuinely useful) teardown of their webpage. No corporate audit speak. No boring SEO reports. Just a tiny goblin telling you exactly what is killing your conversion confidence.

**How it works:**

1. 🧌 Click the goblin icon on any webpage
2. ⚡ Get an instant Goblin Score (0–100) based on real page signals
3. 📋 See the biggest crimes — trust gaps, dead CTAs, buzzword overload, buyer confusion
4. 🚀 Click "Open Full Roast" for a shareable, detailed report at pagegoblin.org

**What the goblin checks:**

- 🔍 **Trust Tax** — Are there testimonials, case studies, client logos, or any proof you are real?
- 💀 **CTA Corpse** — Is there a clear call-to-action, or is it hiding like it owes someone money?
- 📢 **Fluff Damage** — How many buzzwords before the goblin finds actual substance?
- 😵 **Buyer Confusion** — Can a visitor tell what you do, who it is for, and what happens next?
- 🔄 **Conversion Friction** — Is there a clear path forward, or are visitors lost in a maze?

**Privacy is non-negotiable:**

- ✅ The goblin only wakes up when YOU click. No auto-scanning. Ever.
- ✅ Only activeTab access — no persistent all-site permissions
- ✅ No background monitoring, no browsing history, no hidden uploads
- ✅ Page signals are extracted locally — your data stays in your browser until YOU choose to send it
- ✅ Private pages (localhost, dashboards, login screens) trigger a warning before any data leaves

**The goblin is funny, not mean.** It roasts the webpage, not the people. It focuses on trust, clarity, copy, and conversion — and every complaint comes with a genuinely useful fix.

Perfect for:

## Single-purpose justification (for Chrome Web Store review)

PageGoblin has a single purpose: to review a webpage's trust, clarity, copy, CTA, and conversion weaknesses in a playful website-roast format. The extension extracts page signals only when the user explicitly clicks the roast button, runs a local analysis, and optionally sends the extracted signals to pagegoblin.org for a full report — only when the user explicitly chooses to do so.

## Permission justification

- **activeTab**: Needed to read the current page's content (title, headings, CTAs, trust signals) when the user clicks the roast button. No persistent access.
- **scripting**: Needed to inject the signal extraction function into the active tab on user action. No remote code is executed.
- **storage**: Used to save recent local roasts and user preferences locally. No data is synced or sent to a server without explicit user action.

## Privacy practices

**Data collected**: Page signals (URL, page title, heading text, CTA text, trust indicator text, link/button counts) — ONLY when the user explicitly clicks "Roast This Page". This data is processed locally in the browser.

**Data sent to remote server**: Page signals are sent to pagegoblin.org ONLY when the user explicitly clicks "Open Full Roast". The user is warned before sending if the page appears to be private/internal.

**No data collected automatically.** No browsing history, no background scanning, no analytics, no tracking.

**Authentication**: Not required for the quick roast. Optional account creation on pagegoblin.org for saving roast history.
